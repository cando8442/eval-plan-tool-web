# 평가계획서 자동 생성 도구 — 웹 공유판 (eval_plan_tool_web)

`eval_plan_tool`(로컬 hwp 자동생성판)에서 갈라져 나온 프로젝트입니다. 학교 교무부 양식에 따라 매 학기 과목별로 제출해야 하는 두 문서 — 교수학습 및 평가계획서, 평가계획표(.xlsx) — 를 브라우저 폼에 한 번 입력하는 것으로 준비하는 웹 도구입니다.

- **평가계획서**: hwp 파일을 직접 생성하지 않습니다. 대신 폼 입력값 + 콘텐츠 라이브러리 내용을 사람이 읽기 좋은 HTML(제목/표/목록)로 화면에 보여주고, "구글독스용 내용 복사" 버튼으로 클립보드에 복사해 구글독스 등 원하는 문서에 직접 붙여넣도록 합니다(`doc_text_renderer.py`의 `render_plan_html`).
- **.xlsx**: openpyxl로 템플릿(`templates_src/base_planning_table.xlsx`)의 지정된 셀에 폼 데이터를 그대로 써서 저장하고, `/api/download/<request_id>/<filename>`으로 다운로드합니다(요청마다 무작위 `request_id` 하위 디렉터리를 써서, 로그인 없는 공개 배포에서도 다른 사용자가 파일명을 추측해 남의 결과물을 열람할 수 없습니다).

`eval_plan_tool`은 pyhwpx(한글 COM 자동화)로 실제 .hwp/.docx 파일을 생성했으나, 이 방식은 한글(HWP) 프로그램이 설치된 개인 PC에서만 동작해 웹앱으로 공유할 수 없었습니다. 이 갈래는 hwp 자동 생성 기능을 제거하고, 복사-붙여넣기 + 웹 배포 기반으로 전환한 버전입니다.

## 요구 사항

- `requirements.txt` 기준 Python venv (Flask, openpyxl, pyhwp, gunicorn, pytest)
- 학사일정 파일 업로드(`/api/calendar/upload`) 기능은 여전히 hwp 형식의 학사일정표를 입력으로 받아 `hwp5proc`(pip 패키지 `pyhwp`가 제공, 실제 한글 프로그램은 필요 없는 순수 파이썬 구현)로 파싱합니다.

## 배포 (Render)

저장소 루트의 `render.yaml`을 그대로 사용합니다 — Render 대시보드에서 "New +" → "Blueprint"로 이 GitHub 저장소를 연결하면 빌드(`pip install -r requirements.txt`)/시작(`gunicorn app:app`) 커맨드가 자동으로 적용됩니다. 별도 데이터베이스나 영속 디스크는 필요 없습니다(생성 파일은 임시 디렉터리에 요청 단위로만 존재). 필요하면 `EVAL_PLAN_OUTPUT_DIR` 환경변수로 출력 디렉터리를, `HWP5PROC_PATH`로 `hwp5proc` 실행 경로를 덮어쓸 수 있습니다.

## 실행 방법

```
.venv\Scripts\python app.py
```

이후 브라우저에서 `http://localhost:5000` 접속. 폼은 5단계 위저드입니다: 기본정보 → 학사일정 → 반영비율 → 성취평가 → 확인·생성. 각 단계의 필수 입력을 채워야 "다음"으로 넘어가며, 진행 표시줄의 이전 단계를 클릭하면 검증 없이 자유롭게 돌아갈 수 있습니다. 콘텐츠 라이브러리에 이미 있는 과목(예: 공통수학1, 공통수학2, 대수)을 입력하면 미리보기에 해당 내용이 자동으로 채워집니다. 2단계(학사일정)에서 학사일정 파일을 분석하면 월별 주·차시가 월별 계획 입력란에 자동으로 채워지며, 단원명·성취기준 등 나머지는 최대 5개 월까지 직접 입력할 수 있습니다.

3단계(반영비율)의 중간·기말고사 반영비율은 선택 입력입니다 — 비워두면 검증 경고만 뜨고 미리보기에는 "(미입력)"으로 표시됩니다. 수행평가 항목은 기본 4칸이 보이고("+ 항목 추가"로 5개까지), 비워둔 칸은 무시됩니다. 각 항목 카드에는 과목의 콘텐츠 라이브러리에서 뽑은 단원명 체크박스, 체크된 단원명에 맞는 성취기준만 불러오는 "불러오기" 버튼, 기본점수 입력란, 그리고 수행평가 명 기반으로 상/중/하 3단계 루브릭 초안을 만들어주는 "루브릭 생성하기" 버튼(전부 편집 가능)이 있습니다.

5단계(확인·생성)에서 "문서 생성"을 누르면:
1. 엑셀(.xlsx)이 서버에 생성되고 다운로드 링크가 뜹니다.
2. 같은 내용이 화면에 미리보기로 렌더링되며, "구글독스용 내용 복사" 버튼으로 표/목록 서식이 유지된 채 클립보드에 복사됩니다(구글독스에 Ctrl+V로 붙여넣기).

지원 과목: `subjects/2022/수학/` — 공통과목(공통수학1, 공통수학2), 일반선택(대수, 미적분Ⅰ, 확률과 통계), 진로선택(미적분Ⅱ, 기하, 경제수학, 인공지능 수학), 융합선택(실용통계, 수학과제 탐구) 11개 과목(2022개정). 과목명 입력란은 콘텐츠 라이브러리에 등록된 과목을 드롭다운으로 골라 자동 입력할 수도 있고, 직접 타이핑해도 됩니다 — "미적분1"처럼 로마 숫자(Ⅰ/Ⅱ) 대신 일반 숫자로 입력해도 같은 과목을 찾도록 `content_library.load_subject()`에 자동 변환 폴백이 있습니다. 신규 성취기준/성취수준 데이터는 실제 2022개정 교육과정 고시문·복수 출처를 교차 확인해 작성했으나, 일부 세부 문구(특히 원문 PDF를 직접 확인하지 못한 항목)는 큰 틀만 검증되고 세부 표현은 재구성한 것이라 실제 제출 전 검토가 필요합니다(각 JSON의 `source_note` 참고). 다른 과목은 같은 스키마로 JSON을 추가하면 됩니다 — 이 목록에 없는 과목명을 입력하면 콘텐츠 라이브러리 경고와 함께 서술형 항목이 빈 채로 나옵니다.

## 성취기준 출처 — 어디까지 믿어도 되는가

과목 JSON의 성취기준은 두 종류다. 이 구분은 사람이 읽는 `source_note` 와 별개로
`standards_source.verified` 필드에 기계가 읽을 수 있게 박혀 있고, 앱이 이걸 보고
성취기준 선택 화면에 배너를, 생성 결과에 경고를 띄운다.

| 교과 | 과목 수 | 성취기준 | 상태 |
| --- | ---: | ---: | --- |
| 과학과 | 17 | 272 | ✔ 교육부 고시 제2022-33호 [별책 9] 원문 대조 |
| 국어 | 8 | 95 | ✔ 교육부 고시 제2022-33호 [별책 5] 원문 대조 |
| 사회과 | 21 | 127 | ⚠ 미대조 (재구성 초안) |
| 수학 | 11 | 171 | ⚠ 미대조 (재구성 초안) |
| 영어 | 7 | 45 | ⚠ 미대조 (재구성 초안) |
| 한국사 | 2 | 14 | ⚠ 미대조 (재구성 초안) |

미대조 과목의 성취기준은 **문구·개수·코드가 실제 고시와 다르다**. 실제로 과학과
17개 과목은 원문 대조 전까지 과목당 6개씩만 들어 있었고(원문은 14~19개),
성취기준 코드 접두사가 틀린 과목이 5개 있었다(`12생유`→`12유전`, `12역에`→`12역학`,
`12전양`→`12전자`, `12화반`→`12반응`, `12과역`→`12과사`). 미대조 과목도 같은 상태로
보아야 한다.

### 미대조 교과를 원문으로 교체하는 법

`scripts/curriculum/apply_from_pdf.py` 가 그 작업을 한다. 국가교육과정정보센터
(<https://ncic.re.kr> 교육과정 자료실)에서 해당 별책 PDF를 받아두고:

```bash
pip install pdfminer.six

# 1) PDF -> 텍스트
python -m scripts.curriculum.apply_from_pdf --extract 별책7_사회과.pdf soc.txt

# 2) 어떤 과목 코드가 잡히는지 확인 (여기 나오는 접두사로 매핑을 만든다)
python -m scripts.curriculum.apply_from_pdf --list soc.txt

# 3) 매핑 작성: {"과목파일명": ["원문코드접두사", 학기]}  학기는 1 또는 2
cat > map_soc.json <<'JSON'
{"통합사회1": ["10통사1", 1], "통합사회2": ["10통사2", 2], "정치": ["12정치", 1]}
JSON

# 4) 드라이런으로 확인한 뒤 --write 로 반영
python -m scripts.curriculum.apply_from_pdf \
    --text soc.txt --dir "subjects/2022/사회과" --map map_soc.json \
    --document "교육부 고시 제2022-33호 [별책 7] 사회과 교육과정" --write

pytest tests/test_standards_source.py
```

반영하면 성취기준 전체가 한 학기(월별 계획 5행)에 배치되고, 틀린 코드 접두사가
교정되며, `standards_source.verified` 가 `true` 로 바뀌어 경고 배너가 사라진다.

몇 가지 주의할 점이 스크립트에 이미 반영되어 있다.

- **월은 정확히 5개여야 한다.** `static/form.js` 의 `MAX_MONTHLY_ROWS` 가 5이고,
  라이브러리의 월을 숫자가 아니라 "학기 진행 순서상 몇 번째 달인가"로 위치
  매칭하기 때문이다. 3개월치만 있으면 뒤 두 달 행이 빈 채로 문서가 나온다.
- **2학기 과목은 9~1월이 아니라 8~12월로 적는다.** `units_by_month` 를
  `sorted(key=int)` 로 정렬하므로 1월이 맨 앞으로 튀어 학기 순서가 뒤집힌다.
- **고시문에 영역이 없는 과목은 단원명을 지어내지 않는다.** 국어 선택 과목처럼
  성취기준이 전부 `01-xx` 인 과목은 단원 구분이 원문에 없어서 과목명을 넣어 둔다.
- **성취수준(A~E)·최소 성취수준 진술문은 고시문에 없다.** 한국교육과정평가원
  성취수준 자료 소관이라 이 스크립트가 건드리지 않으며, 여전히 재구성본이다.

## 현재 커버리지

미리보기(`render_plan_html`)는 다음 9개 섹션을 렌더링합니다: 표지 정보 / 성적 산출 방식 / 평가 목적 / 평가 방향 / 월별 교수학습 운영 계획 / 최소 성취수준 보장 지도 / 성취수준(A~E) / 평가영역 및 반영비율(+분할점수) / 수행평가 세부계획(성취기준·채점기준표 포함). 콘텐츠 라이브러리에 없는 과목은 서술형 섹션(평가 목적/방향/최소성취수준/성취수준)이 비어 있는 채로 표시되고, 생성 결과에 경고 문구가 함께 뜹니다.

hwp의 정확한 표 서식(칸 병합, 문구 위치 등)을 그대로 재현하지는 않습니다 — 같은 정보를 표/목록 형태로 다시 구성한 것이므로, 구글독스에 붙여넣은 뒤 학교 서식에 맞춰 다듬는 것을 전제로 합니다.

**xlsx는 폼에 입력한 실제 데이터로 정확히 채워집니다.**

이는 설계 문서(`docs/superpowers/plans/2026-07-26-eval-plan-generator-plan.md`) 기준으로 시작된 MVP에서, 이후 hwp 자동 생성을 복사-붙여넣기 방식으로 전환한 상태입니다.
