# 2026학년도 교수학습 및 평가계획서 자동 생성 도구 — 설계

## 배경 / 목적

학교 교무부 양식에 따라 매 학기 과목별로 제출해야 하는 두 문서를 자동/반자동으로 만드는 로컬 도구.

- 한글 파일: `OO학년도 교수학습 및 평가 계획서(N학기-과목명)` — 서술형 계획서
- 엑셀 파일: `OO학년도 N학년 N학기 평가계획표(과목명)` — 학교 전체가 취합하는 1과목=1행 요약표

두 파일은 내용이 100% 일치해야 하며(원본 안내문구: "모든 내용이 평가계획서와 일치해야 합니다"), 지금은 각 교과 교사가 두 파일을 따로 손으로 채우고 있음. 이 도구는 폼 한 번 입력으로 두 파일을 동시에 생성해 교사의 반복 작업과 두 파일 간 불일치 위험을 줄이는 것이 목적.

실제 배포된 예시 파일 3세트(공통수학1, 대수, 인공지능수학 — hwp+xlsx 쌍)를 pyhwp/openpyxl로 직접 열어 구조를 확인한 뒤 이 설계를 작성함.

## 범위

**포함 (MVP)**
- 수학 교과군, 2015 개정 + 2022 개정, 공통/일반선택/진로선택 과목
- 로컬 Flask 웹앱(브라우저 폼) + pyhwpx(한글 COM 자동화)로 실제 .hwp 생성 + openpyxl로 .xlsx 생성
- 수행평가 항목 최대 4개
- 결과물은 로컬 폴더 저장까지만 (Drive 업로드는 교사가 직접)

**제외 (이후 확장)**
- 수학 외 교과 콘텐츠 라이브러리 (요청 시 그때그때 추가)
- Perplexity 실시간 API 폴백 (라이브러리에 없는 과목은 안내 문구만 표시)
- Drive 자동 업로드
- 수행평가 4개 초과, 월별 표 5개월 초과 등 완전 가변 레이아웃

## 아키텍처

```
[브라우저: localhost:5000] --폼 제출--> [Flask 서버]
                                           |
                                           ├─ subjects/{2015,2022}/수학/*.json (콘텐츠 라이브러리, 조회만)
                                           ├─ templates/base.hwp (전 과목 공유 스켈레톤 1개 — 표 구조·서식은
                                           │   과목마다 동일하고 텍스트만 다름을 xlsx 예시 시트 비교로 확인함.
                                           │   모든 가변 셀은 {{TOKEN}} 형태로 미리 치환해둔 빌드 산출물)
                                           ├─ pyhwpx의 find_replace_all(토큰, 값)을 토큰별로 반복 호출 → 출력 .hwp
                                           └─ openpyxl로 xlsx 템플릿 셀 채우기 → 출력 .xlsx
                                           |
                                     결과 저장: C:\Users\cando\평가계획서_출력\
```

- Flask를 쓰는 이유: 폼이 복잡함(월별 표, 반영비율 그리드, 수행평가 블록 반복, 채점기준 표 동적 행) — HTML/JS가 tkinter보다 다루기 쉬움. 로컬 실행이라 배포/보안 이슈 없음.
- pyhwpx는 이 PC에 등록된 `HWPFrame.HwpObject` COM 객체를 통해 실제 한글 프로그램을 조작하므로, **한글 프로그램이 설치·실행 가능한 이 PC에서만 동작**. 여러 문서를 연속 생성할 때는 한글 인스턴스를 재사용하고, 생성 직후 반드시 새 창을 닫아 팝업(자동저장/보안모듈 등)이 쌓이지 않게 처리.

## 실제 문서 구조 (원본 파일 확인 결과)

### 한글 파일 섹션 순서
1. 표: 대상학년 / 과목명 / 학점 / 담당교사(전체 명단) / 성적산출방식선택
   - **2022개정을 고르면 선택 UI 없이 석차등급(1-5)+성취도5단계(A-E)에 자동으로 O,O 고정** (사용자 원 요청: "2022 개정교육과정부터는 석차등급1-5이고 성취도5단계로 일괄 적용")
   - **2015개정을 고르면** 석차등급/성취도5단계/성취도3단계/이수여부/기타 5종을 **중복 허용 다중선택** 체크박스로 노출
2. 표: 월별 계획 — 학기당 정확히 5개월 고정행(1학기 3,4,5,6,7월 / 2학기 8,9,10,11,12월). 컬럼: 시기(월/주(시수)) · 단원명 · 교육과정 성취기준 · 수업방법 · 평가방법(수업-평가 연계 주안점) · 사회정서교육(2차시)
3. "1. 평가 목적" — 서술형 3항(가/나/다), 교과군 공통 문구(전 과목 거의 동일)
4. "2. 평가 방향 및 방침" — 서술형 3~5항, **과목마다 다름** (지식·이해/과정·기능/가치·태도 관점 포함)
5. "3. 성취평가제 적용"
   - 가. 학기 단위 성취수준: A~E(성취도3단계 과목은 A~C) 행. **표 구조는 2열(성취수준 / 학기단위 성취수준)이고, 오른쪽 셀 하나에 "(지식·이해) ... (과정 기능) ... (가치·태도) ..."가 라벨을 붙인 채 한 문단으로 이어짐** — 지식이해/과정기능/가치태도를 별도 컬럼으로 착각하지 말 것. 콘텐츠 라이브러리에는 3필드로 나눠 저장하되, hwp/xlsx에 쓸 때는 라벨+줄바꿈으로 합쳐서 한 셀 문자열로 렌더링하는 조립 단계가 필요함
   - 나. 최소 성취수준 진술문: 대단원별 행 × (영역/영역별 성취수준(E)/성취기준별 성취수준(E)/최소 능력의 수행 특성). "성취기준별 성취수준(E)"과 "최소 능력의 수행 특성" 칸도 마찬가지로 번호 매긴 여러 문장이 한 셀 안에 이어짐(리스트를 줄바꿈으로 합쳐서 렌더링)
6. "4. 평가 영역 및 반영 비율" — 지필(중간/기말: 선택형·서논술형·단답형·합계·반영비율·성취평가방식) + 수행평가(유형·영역명·시기·점수·반영비율, 항목당 1행)
7. "5. 수행평가 세부 계획" — 항목별(제목+배점) 블록: 교육과정영역 / 평가과제 / 성취기준 / 기본점수 / 결시자·학적변동자·특수학생 평가방법 / 표절행위 처리기준 / 채점기준표(영역·척도·채점기준·배점)
8. "6. 수행평가 성취 수준" — 분할점수 표(A/B, B/C, C/D, D/E, E/I). 고정분할 과목은 이 섹션 전체 삭제.

### 엑셀 파일 구조 (`★계획★(여기에 작성 요망)` 시트, 1과목=1행)
- A4:E4 헤더: 학년 / 과목명 / 학점수 / 작성자 / 과목담당 전체교사명단
  - **주의**: hwp 쪽에는 "담당교사"(전체 명단) 필드만 있고 "작성자"(폼을 채우는 1인) 필드가 따로 없음. 폼에는 "작성자"와 "전체 교사명단"을 **별도 입력란 2개**로 받아서, hwp에는 전체명단만, xlsx에는 둘 다 채워야 함
- F~J: 중간고사(선택형/서논술형/단답형완성형/합계/반영비율), K~O: 기말고사(동일 구성)
- P~Y: 수행평가 최대 9영역 슬롯 — 3행 세트(유형선택, 영역명, 평가시기(월)) + 6행(반영비율%)
- Z6: 수행평가 반영비율 합계(자동), AA6: 성취평가방식(추정분할/고정분할), AB6~AF6: 분할점수(A/B~E/I)
- AG6: 서논술형(정기+수행) 학기말 반영비율 자동계산 수식
- A9~C14: 자동 검증 메시지(IF 수식) — 2학점 이하 과목은 수행평가 총비율 20%↑, 3학점 이상은 [서논술형(정기+수행)] 30%↑ AND [수행평가 총비율] 40%↑, 성취평가방식 필수, 분할점수(A/B~D/E) 필수

이 검증 로직을 Flask 폼에서 JS로 동일하게 재현해 실시간 경고 표시.

## 알려진 제약 / 리스크

- **검증 완료(2026-07-26)**: pyhwpx로 실제 hwp 파일을 열어(`hwp.open`) `get_into_nth_table(0)`으로 표 진입, `TableCellBlock()`+`Delete()`+`insert_text()`로 셀 내용을 덮어쓰고 `save_as()`로 저장한 뒤, `hwp5proc xml`로 재추출해 실제로 반영된 것을 확인함(hwp5txt는 표 내용을 아예 추출 못 하므로 검증에 못 씀 — 반드시 `hwp5proc xml` 사용). 이 결과로 아래 "토큰 치환" 방식을 채택: 표 셀 좌표 탐색은 **베이스 템플릿을 한 번 만들 때만** 쓰고, 실행 시점에는 `find_replace_all(토큰, 값)`만 반복 호출하는 훨씬 단순하고 안전한 방식으로 설계를 변경함.
- 표 구조를 조금이라도 건드리면(행 삽입 등) 좌표가 틀어질 위험 → 수행평가 항목 수는 템플릿에 미리 배치한 최대 4블록 내에서 채우고 안 쓰는 블록은 빈칸 처리(삭제 대신).
- "월별 단원 자동분배"는 일반화된 알고리즘이 아니라, 조사 시점에 한 번 정한 예시 분배안을 그대로 제공하는 것. 학교 시험 일정·실제 진도가 다르면 교사가 직접 월을 조정해야 함 — UI 문구도 "자동 배분" 대신 "참고 초안"으로 표현할 것.
- "분할점수 전국 평균"은 공개된 공식 통계가 없음 — 원본 예시값을 "참고 예시"로만 제공하고 사실처럼 단정하지 않음.
- 이 도구는 한글 프로그램이 켜져 있는 이 PC에서만 동작(서버 배포 불가). 한글 미설치·충돌 시의 에러 메시지 처리는 구현계획에서 별도로 다룰 것(이 설계에는 미포함).

## 추가 기능: 학사일정 업로드 → 월별 주·차시 자동 계산

사용자 추가 요청(2026-07-26): 학사일정 파일(한글/pdf, 월달력 그림형 표)을 업로드하면 월별 표의 "주(시수)" 칸(예: "1~4주 (16)")을 자동으로 계산해준다. 사용자는 파일 업로드 방식을 명시적으로 선호(파싱 정확도가 낮을 수 있음을 인지하고 수용).

- 달력 그림형 표는 레이아웃 인식이 어려워 100% 정확한 파싱은 불가능 — **추출 후 반드시 교사가 확인/수정하는 단계를 거침** (자동확정 아님)
- 처리 흐름: hwp5proc xml(한글) 또는 pdf 텍스트 추출(pdf)로 원문 텍스트 확보 → 정규식으로 날짜 패턴(`3.2.`, `3/2`, `2026-03-02` 등)과 학사 이벤트 키워드(중간고사·기말고사·방학식·개학식·재량휴업일·시업식·종업식 등) 후보 추출 → 후보 목록을 폼에 표로 보여주고 교사가 삭제/추가/수정 → 확정된 "제외기간" 목록 + 학기 시작·종료일 + 교사가 선택한 수업요일(4단위면 요일 4개 등)로 순수 날짜 연산을 수행해 월별 "N주(M차시)" 계산
- 실제 학사일정 파일 샘플을 아직 확보하지 못해, 정규식 휴리스틱은 구현 단계에서 실제 파일로 보정이 필요함(리스크로 기록)

## 테스트 계획
- 콘텐츠 라이브러리 JSON: 스키마 검증(필수 키 존재) 단위 테스트
- xlsx 생성: 생성된 셀 값이 원본 예시 파일과 동일한 셀 좌표에 들어가는지 비교 테스트, 검증 수식 로직(JS/Python) 유닛 테스트
- hwp 생성: 실제 pyhwpx로 1개 과목 end-to-end 생성 후 hwp5txt로 재추출해 입력값이 반영됐는지 확인 (수동 검증 1회 필수 — 자동화된 hwp diff는 신뢰도 낮음)
